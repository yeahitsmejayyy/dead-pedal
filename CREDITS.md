# Credits

All game code is original. Audio is third-party and licensed as below.

## Attribution required

- **Rocket Launch Pack** by *dklon* — https://opengameart.org/content/rocket-launch-pack —
  licensed **CC-BY 3.0** (https://creativecommons.org/licenses/by/3.0/).
  Used for `public/audio/rocket_launch_a.ogg` and `rocket_launch_b.ogg`.

This is the only asset in the project carrying an attribution obligation. It is here because
there is no CC0 rocket-launch recording that works, and the alternative was keeping a
synthesised launch that did not sound like anything leaving a car.

## CC0 / public domain — no obligation

Credited voluntarily; none of these require it.

- **The Free Firearm Sound Library** — Ben Jaszczak, Brian Nelson, Kevin Heras, Matthew Nanney —
  https://opengameart.org/content/the-free-firearm-sound-library — CC0.
  Machine gun fire (5 variants).
- **Metal Impact Sounds** — Brian MacIntosh (BMacZero) —
  https://opengameart.org/content/metal-impact-sounds — CC0.
  Bullet-on-metal impacts (3 variants).
- **Impact Sounds** — Kenney — https://kenney.nl/assets/impact-sounds — CC0.
  Bullet-on-metal impacts (2 variants), car impacts.
- **Kenney** — https://kenney.nl — CC0. Interface and UI sounds: pickup, lock-on, mine arming,
  mine pulse, countdown beep.
- Explosions and wreck sounds — CC0, sourced from OpenGameArt CC0 packs.

Every file was licence-checked against its source page and, where a pack shipped its own
LICENSE file, against that file directly. One candidate pack was rejected during that check:
its OpenGameArt page claimed CC0 while the archive contained a `creativecommons.txt` asserting
CC-BY 3.0 on behalf of the original author. Nothing from it is used here.
